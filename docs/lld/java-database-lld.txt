Relationship

DatabaseServer
      │
      ├── owns ▶ QueryEngine
      │              │
      │              └── DefaultQueryEngine coordinates
      │                        ├── owns ▶ QueryLexer  → Token (TokenCatalog)
      │                        └── owns ▶ QueryParser → AstNode
      └── owns ▶ NetworkModule
                    │
                    ├── creates/owns ▶ RequestHandler(queryEngine)
                    └── ServerSocket → ClientConnection

Design note:
DatabaseServer owns NetworkModule and QueryEngine (constructor injection).
NetworkModule owns RequestHandler.
DefaultQueryEngine owns QueryLexer and QueryParser; execute() lexes then parses then echoes.
Lex errors become the response via LexException.toResponse() (exact 0-based index).
Lexer types live under com.example.database.engine.lexer.
Parser types live under com.example.database.engine.parser.
DatabaseServer passes QueryEngine into NetworkModule; NetworkModule assigns it to RequestHandler.
RequestHandler bridges network and query engine.
java.net.Socket classes stay inside the TCP implementations.
