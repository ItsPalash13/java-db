Relationship

DatabaseServer
      │
      ├── owns ▶ StorageEngine  → DataDirectory
      ├── owns ▶ QueryEngine
      │              │
      │              └── DefaultQueryEngine coordinates
      │                        ├── owns ▶ QueryLexer  → Token (TokenCatalog)
      │                        ├── owns ▶ QueryParser (DefaultQueryParser)
      │                        │              ├── ParserRegistry → Select/Update/Insert/Delete/Create/Alter/DropParser
      │                        │              └── AstNode (Query / Expression)
      │                        └── uses ▶ StorageEngine (shared)
      └── owns ▶ NetworkModule
                    │
                    ├── creates/owns ▶ RequestHandler(queryEngine)
                    └── ServerSocket → ClientConnection

Design note:
DatabaseServer owns StorageEngine, NetworkModule, and QueryEngine (constructor injection).
NetworkModule owns RequestHandler.
DefaultQueryEngine owns QueryLexer and QueryParser; uses StorageEngine (does not own its lifecycle).
execute() lexes then parses then echoes.
Lex/parse errors become the response via LexException/ParseException.toResponse() (exact 0-based index).
Lexer types live under com.example.database.engine.lexer (unchanged names).
Parser types live under com.example.database.engine.parser.
DefaultQueryParser dispatches via ParserRegistry; statement parsers own grammar; AST holds structure.
DatabaseServer passes QueryEngine into NetworkModule; NetworkModule assigns it to RequestHandler.
RequestHandler bridges network and query engine.
java.net.Socket classes stay inside the TCP implementations.
